PLUGINS ARCHITECTURE

==================================================

The system supports a WordPress-style plugin marketplace.

Plugin Repository:
All available plugins are stored inside `docs/plugins/`. Each plugin folder contains its frontend code and a `plugin.json` metadata file.

Backend API:
The `PluginsController.cs` handles physical file operations to simulate installation:
- GET `/api/plugins/available`: Parses `plugin.json` from the repository.
- POST `/api/plugins/install/{id}`: Copies files from the repository to `Frontend/admin/components/`.
- DELETE `/api/plugins/{id}`: Erases the files from `Frontend/admin/components/`.

Frontend (plugins-manager.js):
Fetches the plugin list, manages search/filtering, triggers backend installation/deletion, and stores "active" state inside `localStorage` for UI toggling.
